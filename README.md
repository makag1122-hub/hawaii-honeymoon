# 🌺 우리 둘의 알로하

휴대폰에서 쓰는 작은 하와이 여행 다이어리입니다. 일정, 예상 비용과 실제 지출, 예약 서류, 준비물을 한곳에서 관리합니다. 크림색 종이와 민트·코랄색, 거북이 커플을 담았습니다.

공개 사이트는 비어 있는 앱입니다. 개인 여행 자료는 직접 불러온 브라우저의 IndexedDB에만 저장하며 서버로 전송하지 않습니다. 두 휴대폰의 자료는 각각 보관됩니다.

## 휴대폰에서 시작하기

1. Chrome 또는 삼성 인터넷에서 사이트를 엽니다.
2. 개인 여행 ZIP을 불러오고 내용을 확인합니다. 기존 자료가 있다면 백업 후 교체합니다.
3. 인터넷이 연결된 상태로 **오프라인 준비 완료**가 표시될 때까지 기다립니다. 앱과 글꼴, 그림, PDF 뷰어의 필수 파일을 내려받습니다.
4. Chrome 메뉴의 **홈 화면에 추가 / 앱 설치**, 또는 삼성 인터넷 메뉴의 **현재 페이지 추가 → 홈 화면**을 선택합니다. 메뉴 이름은 브라우저 버전에 따라 다를 수 있습니다.
5. 비행기 모드에서 앱을 다시 열어 일정과 예약 PDF가 보이는지 확인합니다.

지도와 외부 예약 사이트는 인터넷이 필요합니다. PDF는 가져온 원본을 기기에 저장하므로 오프라인에서도 확대하거나 페이지를 넘길 수 있습니다.

## 저장·백업·다른 폰으로 옮기기

- 편집 내용은 현재 브라우저에 저장됩니다. 같은 폰이라도 Chrome과 삼성 인터넷의 저장 공간은 별개입니다.
- 설정에서 ZIP 백업을 내보내 보관합니다. 공유 기능을 쓸 수 없는 브라우저에서는 다운로드한 ZIP을 직접 공유하세요.
- 다른 휴대폰에서 ZIP을 불러오면 해당 폰의 기존 자료 전체를 교체합니다. 자동 동기화와 병합은 없습니다.
- 브라우저의 사이트 데이터 삭제, 앱 데이터 초기화, 저장 공간 정리로 기기 자료가 사라질 수 있으므로 수정 후 백업을 보관하세요.
- ZIP에는 일정과 금액, 메모, 첨부된 원본 PDF가 포함됩니다. ZIP 파일은 필요한 사람에게만 전달하세요.
- 새 앱 버전이 준비되면 업데이트 안내가 표시됩니다. 앱 업데이트는 저장된 여행 자료를 유지합니다.

## 로컬 개발과 확인

Node.js 22를 사용합니다.

```sh
npm ci
npm run dev
```

오프라인 기능은 개발 서버에서 등록하지 않습니다. 배포 빌드로 확인합니다.

```sh
npm test
npm run build
node scripts/privacy-check.mjs
npm run preview
```

미리보기 주소는 `http://localhost:4173/hawaii-honeymoon/`입니다. 실제 단말에서 오프라인 설치를 확인할 때는 HTTPS 배포 주소를 사용하세요.

## GitHub Pages 배포

저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다. `main`에 앱 코드를 올리면 워크플로가 테스트, 빌드, 공개 파일 검사를 마친 뒤 `dist`만 배포합니다. 다른 저장소 이름을 사용할 경우 `vite.config.ts`의 `base`도 변경하세요. [Vite 공식 배포 안내](https://vite.dev/guide/static-deploy.html#github-pages)

공개 저장소에는 앱 코드와 일반 아이콘만 둡니다. 실제 여행 원본, ZIP, PDF, 개인정보가 담긴 테스트 화면은 저장소 밖에 보관합니다. `.gitignore`와 배포 검사로 원본 서류·백업 파일 형식 및 비공개 산출물 경로를 차단합니다. 검사는 모든 개인정보를 자동으로 판별하지 않으므로 공개 커밋 내용도 확인해야 합니다.

개인 문자열을 추가로 검사하려면 저장소 밖에 문자열 배열 JSON을 준비합니다. 검사 로그에는 실제 문자열을 출력하지 않습니다.

```sh
node scripts/privacy-check.mjs --markers-file ../private-markers.json
```

앱은 React·TypeScript·Vite, IndexedDB, PDF.js, fflate, Vite PWA를 사용합니다. PDF.js의 CMap·기본 글꼴·WASM·ICC 자료와 앱 글꼴을 같은 사이트에서 제공하고 사전 저장합니다. 서비스 워커는 외부 사이트를 저장하지 않습니다. 앱 업데이트는 [Vite PWA의 사용자 확인 방식](https://vite-pwa-org.netlify.app/guide/prompt-for-update.html)을 사용합니다.
